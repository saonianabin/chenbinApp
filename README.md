# WMS 仓储管理系统

一个基于 Flutter 3.19.6 开发的完整仓储管理系统，采用工业风格 Material 3 UI 设计，支持全中文界面。

## 功能特性

### 🏢 核心功能
- **库存管理**: 多维度库存展示（现有、可用、冻结库存）
- **采购入库**: 采购收货流程管理，支持审核通过/拒绝
- **销售出库**: 出库核销流程，自动库存扣减
- **任务管理**: 任务生命周期管理（待处理 -> 审核通过/拒绝）

### 📊 实时统计
- 库存水位监控
- 待处理任务统计
- 库存预警提示
- 任务执行情况

### 🔍 智能功能
- 商品搜索（支持名称、SKU）
- 分类筛选
- 扫码模拟
- 实时库存联动

### 🎨 UI 设计
- Material 3 设计语言
- 工业风格深蓝色主题 (#1976D2)
- 全中文界面
- 响应式布局

## 业务流程

### 1. 采购入库流程
1. 创建采购入库任务
2. 添加采购商品明细
3. 审核通过 → 库存自动增加
4. 审核拒绝 → 录入拒绝原因

### 2. 销售出库流程
1. 创建销售出库任务
2. 设置实际出库数量
3. 审核通过 → 库存自动扣减
4. 库存不足时系统自动校验

### 3. 库存管理
- 实时库存数量监控
- 库存预警（库存不足/过量）
- 冻结库存管理
- 多维度库存统计

## 数据模型

### InventoryItem (库存商品)
- 现有库存、冻结库存、可用库存联动计算
- 库存预警（最小/最大库存）
- SKU 管理
- 库位信息

### MovementItem (出入库任务)
- 任务状态：待处理/已通过/已拒绝
- 申请数量与实际数量
- 审核历史记录
- 拒绝原因记录

## 验收标准

✅ **采购收货流程**: 点击审核通过，库存对应 SKU 增加；支持拒绝填理由  
✅ **出库核销流程**: 点击审核通过，库存扣减；实发数量不能超过现有库存  
✅ **库存多维度展示**: 列表清晰展示现有、可用、冻结数量  
✅ **扫码模拟**: 点击扫码图标能模拟定位到特定库存产品  
✅ **全中文 UI**: 所有界面均为中文显示
